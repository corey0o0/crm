# X-RIDER 제원·호환 참고표 (직원용)

> 엑스라이더(slimpack.co.kr) 전동킥보드·전동자전거 제원 모음. 빈칸은 확인 후 채울 것.
> 니어바이크 제원은 별도 문서(니어바이크-제원-호환표) 참조.

## 공통
- **최고속도**: 25km/h 미만(오토컷)
- **구동**: PAS 3단(1=15 / 2=20 / 3=25 km/h) + 스로틀(키박스 우측, 약 20초 유지 시 크루즈모드)
- **배터리**: 볼턴배터리 제작 + LG셀 + BMS
- **프레임**: 알루미늄 (전 모델)
- **법규/면허**: 원동기 이상 면허 필수, 헬멧 착용 의무 / 자전거도로·차도 우측 가능, 인도·2인 탑승 금지
- **보증**: 프레임·모터·배터리 1년 또는 3,000km(1회). 소모품(브레이크·타이어·패드·디스플레이·컨트롤러·유성기어·라이트) 유상

- 전 모델 공통: 알루미늄 프레임, PAS 3단(15/20/25) + 스로틀, 최고속도 25km/h 미만, **크랭크 52T**(터보S 제외), **충전기 48V 2A 기본 제공**.
- 주행거리: 20Ah 70~80km / 35Ah(터보S) 90~100km. 충전: 20Ah 약 10h / 35Ah 약 17~18h (48V 2A 기준).
- **법규 분류**: 일반 모델 = **PM(개인형 이동장치)** → 자전거도로 이용 가능 / **터보S(X200 GT)** = **저속형 이동장치** → 자전거도로 이용 불가(차도 이용).
- **X200 PRO SL** 추가: 앞 유압식 서스펜션 포크 + 뒤 소프트 듀얼 유압 서스펜션, 고급 LED 헤드라이트.
- **X200 MAX SL** 추가: 앞 KKE 서스펜션 포크 + 뒤 KKE 에어 서스펜션 (그 외 사양은 PRO SL과 동일, 최대탑승 120kg).
- **X100 MAX SL** 추가: 앞 유압 서스펜션 포크 / 뒤 서스펜션 없음, 소프트 롱 시트 (그 외 PRO SL과 동일, 최대탑승 140kg).
- **X200 GT (= TURBO S)**: 모터 48V **1500W** SL 고출력 + 배터리 **48V 35Ah 점보**(타 모델은 20Ah 미니점보). **기본 출고 페달 없이 풋페그(발걸이) → 스로틀 주행**(크랭크 미사용). 그 외 PRO SL과 동일, 최대탑승 140kg.
- **X50 FS**: BMX 스타일 프레임, 롱 H핸들 기본, 앞 유압 서스펜션 포크 + 뒤 서스펜션 시트포스트 (그 외 PRO SL과 동일, 최대탑승 120kg).
- ✅ 5종 제원 입력 완료.
