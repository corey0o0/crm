# X-RIDER 제원·호환 참고표 (직원용)

> 엑스라이더(slimpack.co.kr) 전동킥보드·전동자전거 제원 모음. 빈칸은 확인 후 채울 것.
> 니어바이크 제원은 별도 문서(니어바이크-제원-호환표) 참조.

## 공통
- **최고속도**: 25km/h 미만(오토컷)
- **구동**: PAS 3단(1=15 / 2=20 / 3=25 km/h) + 스로틀(키박스 우측, 약 20초 유지 시 크루즈모드)
- **배터리**: 볼턴배터리 제작 + LG셀 + BMS
- **프레임**: 알루미늄 (전 모델)
- **법규/면허**: 원동기 이상 면허 필수, 헬멧 착용 의무 / 자전거도로·차도 우측 가능, 인도·2인 탑승 금지
- **보증**: 프레임·모터·배터리 1년 또는 3,000km(1회). 소모품(브레이크·타이어·패드·디스플레이·컨트롤러·유성기어·라이트) 유상
