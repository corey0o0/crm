2. When clicked, run a loop over `selectedItems`.
3. For each ID:
   a. Fetch shipment by ID
   b. Fetch existing `shipment_parts`
   c. If `product_name` has commas or if we just want to re-analyze based on `product_name`.
      Actually, the user said "내부 파츠 '제품 정보 다시 분석'으로 입력을 할건이 많이 있는데"
      This means they want to apply the logic from `handleAnalyzeProduct` directly to the DB.
   d. The logic:
      - Split `product_name` by comma.
      - For each separated name, find it in the `parts` table.
      - Create new `shipment_parts` array.
      - Delete existing `shipment_parts` for this shipment.
      - Insert the new array.
      - Update the `shipments` table with the new `quantity` and `price` sum if needed. (Wait, in `handleAnalyzeProduct`, it doesn't automatically save to DB until the user clicks "Save". But in bulk, we MUST save to DB).
      - Also, what about `transactions`? If the shipment is `출고완료` (Shipped), we might need to recreate the `transactions`!
      This is tricky because `transactions` must be kept in sync.
